### 0.8.8 发布功能要点（官方 Release Notes）

- **Agent 控制**：中断、转向（steer）、消息排队、工具调用审批（HITL，对应新集合 `toolapprovalgrants`）
- 统一 Agent Builder；同运行 Skill 编写；程序化工具调用；后台工具
- **Scheduled Chats**（cron/时区/项目目标，beta、实验性、默认关闭）
- 代码工作区 / 有状态 Code Interpreter 会话（高度实验性）
- Beta **Agents API**（Chat Completions / Open Responses 兼容）与 Agent Events
- 实验性 Agent 插件（打包 Skills + MCP + hooks）
- 执行可视化：实时活动、工具计时、Context Usage、Langfuse Trace Viewer
- 新模型：GPT-6 / GPT-6.1 Sol、Claude Opus/Sonnet 5.5、Gemini 3.8 Flash
- 租户级 YAML endpoints、凭据边界、更快的流式/渲染
- 配置变更日志 v1.3.15–v1.3.17（`librechat.example.yaml` 版本 1.3.17）

## 三、发布后至 e1dfc1044 的主要增量（本次合并实际带入的部分）

按主题摘选（完整清单见 git log）：

- **未读/通知**：会话未读标记（`isMarkedUnread`、`lastResponseAt` 等）、混合后端版本下的未读意图保持
- **排队/转向**：转向控制简化为三模式；排队轮次支持 `reasoningOverride`；停止生成的流分离前对账
- **代码工作区**：lane Git 状态记录与会话 PR 服务（`laneGit` 等）；No-Workspace 决策贯通；代码机器/工作区继承父 Agent 默认；workspace 检出模式（`checkout`）
- **工具审批（HITL）**：新集合 `toolapprovalgrants` + `toolApprovalAllows`，按会话记忆自动批准
- **余额**：上下文仪表盘中以积分/货币/百分比显示余额；`refillMode`（`balanceReset` 不结转重置）
- **子代理**：与 Handoff 分离为原生工具；子代理命名/头像；按调用选择子代理机器
- **MCP/定时任务**：授权的定时 MCP Resource Bearer；`mcpConsent` 与失败原因/恢复枚举
- **Passkey/WebAuthn 登录**：新集合 `passkeys`
- **安全**：API-Key 头检测要求冒号；并发首次 SAML/LDAP/社交登录恢复；凭据变更时间戳使旧 JWT 失效（`credentialsChangedAt`、`emailChangedAt`）；2FA 注册/确认 nonce
- **性能**：会话列表新索引（endpoint 过滤、默认列表/未读轮询）；文件选择器部分索引；工具调用预览按需加载；消息历史释放
- **UI/主题**：ClickHouse 主题分层表面角色、静音边框、紧凑选择器、tooltip 层级、a11y 焦点环等
- **杂项**：Prompt Group 作为 Agent 指令（`instructionsPrompt`）；Mistral Large 3 计价修正；项目默认不含项目外会话

## 四、运维需关注的配置/环境变化

1. **`UPGRADING.md` 三节必须通读**（本次合并后仓库根即最新版）：
   - Native-only web search（v0.8.8-rc2 后语义变化，`interface.webSearch` 的持久化拒绝语义）
   - Redis 流增量默认 25ms 合并（`STREAM_DELTA_COALESCE_MS=0` 恢复旧行为）
   - 租户索引迁移（仅 v0.8.7 及更早创建的库需要）
2. `librechat.example.yaml` 升至 **config 版本 1.3.17**；新增/变化键：
   `interface.sharedLinks.snapshotFiles`、`registration.openidDiscovery.startupAttempts/retryDelayMs`、
   agent 端点 `statefulCodeSessions.conversationMoves`、`streamRate`、代码环境限制组等。
3. `.env.example` 重要新增（按需评估）：`STREAM_DELTA_COALESCE_MS`、`MONGO_AUTO_INDEX/MONGO_AUTO_CREATE`
   及 Mongo 连接池参数、`SCHEDULES_*`、`USE_REDIS_STREAMS`、`SEARCH/MEILI_*`、
   `FILE_UPLOAD_SSE_ENABLED`、`REMOTE_FILE_FETCH_*`、Admin Panel 三件套
   （`ADMIN_PANEL_URL/SESSION_SECRET/PORT`，SESSION_SECRET ≥32 字符）、CSP 安全头组、
   `CODEAPI_*`（Code Interpreter JWT）、`TRUST_TENANT_HEADER` 等。
4. 运行要求：Node 24（`.nvmrc` = 24.16.0，Docker 基镜像 `node:24.16.0-alpine`）；
   本地开发用 `npm run backend:dev` / `frontend:dev` 不受影响。
5. Docker 构建行为变化：**前端构建失败 now 会导致镜像构建失败**（此前可能静默成功），自定义镜像构建脚本注意。
